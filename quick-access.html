📱 Quick Deck アクセス方法

⚠️ GitHub Pagesが見れない場合
以下の設定を確認してください

1. GitHub設定の確認

  1. リポジトリ設定 → Settings → Pages
  2. Source: "Deploy from a branch" を選択
  3. Branch: claude/quick-deck-v1-prototype-011CUKLPZfdDNwLbY58VKkHR
  4. Folder: /docs を選択
  5. Save をクリック
設定後、数分待ってから以下のURLにアクセス
https://sparkminan.github.io/cedesandbox/

2. すぐに使いたい場合（推奨）

以下のリンクをクリックして、Quick Deckを開いてください：

JSFiddle で開く CodePen で開く

3. ローカルサーバー（同じWi-Fi内）

http://21.0.0.100:8080/index.html

※ iPhoneとコンピューターが同じWi-Fiに接続している必要があります

4. リポジトリが Private の可能性

  1. GitHub リポジトリ → Settings → General
  2. 一番下の "Danger Zone"
  3. "Change repository visibility" で Public に変更

📞 トラブルシューティング

問題: GitHub Pages のURLにアクセスできない

原因候補:

  • リポジトリが Private になっている
  • GitHub Pages の設定が完了していない
  • デプロイに時間がかかっている（最大5分程度）
  • ブランチ名が長すぎる

解決策:

下記のCodePenリンクから直接アクセスすることをお勧めします。
